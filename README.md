# Not Ortalaması Hesaplayıcı

C# ile geliştirilmiş çoklu ders destekli not ortalaması hesaplama uygulaması.

## Özellikler

- Vize ve final notlarını alma
- %40 vize, %60 final ile ortalama hesaplama
- Harf notu belirleme
- Geçti/Kaldı durumunu gösterme
- Birden fazla ders için işlem yapma
- Array kullanımı
- GNO hesaplama

## Kullanılan Teknolojiler

- C#
- .NET
- Visual Studio
